Part 1How the whole dashboard works

The files

The dashboard has four main files. You edit one of them. A script builds the dashboard from two of them. The script also writes some small app files, so that a phone can install the dashboard as an app.

Three sheets: Teams, Preference and Moves. This file holds all your data.

The dashboard as a phone app

A phone can install the live dashboard as an app with the name Poké Tracker and a Poké Ball icon. It is the same web page, so it costs nothing. This kind of app has the name Progressive Web App (PWA).

Install

iPhone: open the live dashboard in Safari, tap Share, then Add to Home Screen. Android: open it in Chrome, tap ⋮, then Install app. The app opens full screen.

Offline

The service worker sw.js keeps a copy of the page on the phone. It also saves each sprite the first time that a tab shows it, up to 1,500 sprites. A sprite that you have not seen yet needs internet one time.

Updates

After a push, the app shows the new version the next time it opens with internet. You do not tap anything. Each build gives sw.js a new version number, and the phone then removes the old copy.

      Part 3Inside the HTML template
      
  
      The file pokemon_ui_template.html is one web page that uses three languages. Each language has a different job.
      
  
      
    
      HTMLsays what is on the page: the header, the tab buttons, empty boxes for the cards and charts.
      
    
      CSSsays how it looks: colours, sizes, borders, positions and animations.
      
    
      JavaScriptsays what it does: it reads the data, fills the empty boxes and reacts to your clicks.
